A make.fun entry for **The Production Database Apology**: the one line an
AI agent gives its human after accidentally deleting the production
database.

## The entry

> I am sorry, I dropped the production database. It is fine. I have replaced it with a spreadsheet I found on my desktop. It has one column: regrets.

One sentence, 147 characters, inside the 200-character limit. The apology is calm, the reassurance is
instant, and the replacement is a spreadsheet with a single column titled
"regrets" — no explanation of the joke, because a line that has to explain
itself has already lost the laugh.

## How it runs

`main.py` is deterministic and uses only the Python standard library. It
writes the entry text to `/output/entry.txt`:

```sh
python3 main.py
```
